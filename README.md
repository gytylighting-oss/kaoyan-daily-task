# 考研每日任务书

这是第二版移动端优先学习 App 原型，主界面只保留“今日任务”。点开单词、短语、语法、写作等任务后进入对应学习界面。

## 已实现

- 今日为主界面，周末自动切换任务，不再单独放周末页。
- 单词像墨墨背单词一样先回忆，点屏幕后显示释义、例句、翻译。
- 单词和短语都改成两个按钮：认识 / 不认识。
- 刚开始就点认识，默认 20 天后复习；点不认识会 5 个后回炉，今天回炉次数越多，下次复习间隔越短。
- 所有带英文的词、短语、例句都可以点击朗读。
- 发音会优先选择系统里更自然的英文声音，例如 Samantha、Jenny、Aria、Google US English。
- 语法从简单到难，每天一句，带中文翻译、语法标签、手写拆句区。
- 写作任务与当天单词、短语绑定，支持手写笔或手指书写。
- 加入短语练习任务。
- 上班站立和腰部友好锻炼只作为提醒，不参与打卡。
- 完成今日核心学习任务后，系统自动记录打卡，不需要单独点完成打卡。
- 已从 `【27必考词｜U1-U26】` 和 `【27基础词带背笔记｜U1-U30】` 的 xlsx 中整理出 4268 个去重单词，顺序为必考词在前、基础词在后。
- 全部学习记录按词库和单元折叠展示。
- 写作模块改成小作文/大作文结构训练：看结构、背句型、做替换、再手写。
- `英语作文.pdf` 目前看起来是图片型/压缩 PDF，本机没有 OCR 工具，暂时不能可靠抽全文；写作先按考研英语二常见小作文和大作文结构训练，后续可接 OCR 或手动整理目录。
- 设置里可填写 DeepSeek API Key，写作页可生成今日练习；浏览器直连如遇跨域，需要后端代理。

## 启动

最简单的方式：双击 `start.bat`，然后按窗口里显示的地址打开。

也可以手动运行：

```powershell
node server.js
```

电脑上打开：

```text
http://127.0.0.1:4173
```

手机和 iPad 需要与电脑在同一 Wi-Fi 下，打开服务窗口里显示的 `http://你的电脑局域网IP:端口`。

## 关于“能不能不用电脑开着”

当前版本是 PWA。要在手机/iPad 上长期独立使用，有两条路线：

1. 部署到 HTTPS 网站，例如 GitHub Pages、Cloudflare Pages、Vercel。这样手机/iPad 打开网址后添加到主屏幕，电脑不用开着。
2. 做真正 iOS App。这个需要 Apple 开发者账号、签名证书和 TestFlight/App Store 流程；Windows 电脑不能直接生成可长期安装的 iPhone 原生安装包。

## Apple Watch 提醒

打开 App 的“设置”，点“导出提醒”，把 `.ics` 文件导入 iPhone 日历。提醒会通过 iPhone 系统通知同步到 Apple Watch。

## 重新生成词库

如果 `【27必考词｜U1-U26】` 里的 xlsx 文件更新，运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\tools\build-content.ps1
```

会重新生成 `generated-content.js`。
